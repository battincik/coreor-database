# v26.11.3 için yayın adımları

1. PR #75 ana dala merge edilmeli ve CI geçmeli.
2. `git switch main && git pull origin main` çalıştır.
3. `npm ci && npm run check` ile yerel doğrula.
4. **Release hazırlanmıştır; `npm run version:prepare` komutunu tekrar çalıştırma.**
5. Ana dalın commit'ini etiketle: `git tag v26.11.3` ve `git push origin v26.11.3`.
6. GitHub Actions → Signed release candidate → Run workflow → `main`.
7. Preflight job'u etiketin commit'e ait olduğunu kontrol eder; platform paketleri oluşturulur.
8. `verify-release` başarılıysa taslak yayının dosyalarını ve release notlarını kontrol ederek yayımla.
9. Kurulu v26.11.1 → Ayarlar → Güncellemeler → Şimdi kontrol et.

Eski `untagged-...` yayına ve v26.11.2 dosyalarına dokunulmaz.

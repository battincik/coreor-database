# Coreor Database v26.11.3

Bu sürüm, büyük veritabanlarında şema performansını geliştiren yenilikleri ve SQL editöründeki tercihlerle birlikte imzalı güncelleme yayın akışı iyileştirmelerini sunar.

## Şema diyagramı
- 25–500 tablo görüntüleme sınırı
- İlişki Hiyerarşisi, Yatay Akış, Dikey Akış, Dengeli Izgara, Yoğun Yerleşim ve Radyal Harita seçenekleri
- %10 minimum yakınlaştırma ve ilk yerleşime dönebilme
- Tablo yüksekliğine duyarlı çakışma koruması; konumların veritabanı bazında kaydedilmesi
- Ekran dışındaki tabloların ve çizgilerin gösterilmemesi; uzak zoom'da sadeleştirme

## SQL editörü
- Otomatik SQL önerilerini kapatma seçeneği
- ALTER onaylarını bağımsız olarak devre dışı bırakma (diğer riskli sorgular korunur)

## Güncelleyici ve yayın güvenilirliği
- Sürüm öncesi Git tag kontrolü
- İmzalı platform paketlerinin manifest bağlantıları ve dosyalarla doğrulanması
- Windows, macOS (Intel / Apple Silicon) ve Linux paketleri

Bu sürüm, eski v26.11.2 release'ini değiştirmez. Kurulu v26.11.1 sürümünden uygulama içi güncelleme üzerinden test edilebilir.

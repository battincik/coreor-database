# v26.11.3 updater download hotfix

The signed v26.11.3 release was published under the temporary GitHub
`untagged-97f649b38c21383fbbbe` tag, despite `v26.11.3` existing and
pointing to the original signed build commit.

This causes updater downloads to return HTTP 404 for the canonical URLs.

The repair workflow is restricted to the existing release ID `445283903` and
original commit `d774c1f8622b3b4ba80ebb93991a8d7e2bdf395f`.

It verifies release identity, package count, version and signatures, links
the release to the existing `v26.11.3` tag, replaces `latest.json` only if
its download URLs are incorrect, and tests anonymous public downloads using
HTTP HEAD for the manifest and Windows installer. Installer archives and
signatures are not rebuilt or modified. The original manifest is retained
until the replacement is validated.

GitHub Actions:
Actions → Repair v26.11.3 published updater downloads → Run workflow.
